Conviction Index — Product Pitch, Feature Plan & Full Rules
The one-liner
A crowd-sourced reputation market built from public chatter. Who in the ecosystem has actually been right, on the record, and what does the crowd believe right now.

Why this is the reason to return
Nobody in the group is trying to be right on purpose — they're hyping in public group chat, unsolicited and on the record. That's a more honest signal than any survey or gated prediction market, because there's no gamification incentive to be conservative or strategic.

And it compounds: every call that resolves, the rep rankings and the consensus number get more trustworthy.

PART A — THE CONVICTION INDEX FORMULA (locked)
This is the app's single most important number. These constants are approved and must not change (per user directive). Reconstructing the engine is validated against the 11 exact test numbers below — 11/11 must pass.

Constants (DO NOT CHANGE)
γ (gamma) = 2.5 — conviction curvature exponent
κ (kappa) = 1.2 — index κ-smoothing
α = β = 3 — Bayesian credibility prior shape
half-life = 24h — recency decay
Direction comes from signed momentum only, NOT reputation
Primary formula
CODE
s(m) = (conviction / 100) ^ 2.5 · sign(direction)
        sign(direction): +1 bull, −1 bear, 0 neutral
W(a) = Author credibility = modest reputation multiplier (Bayesian, α=β=3)
Recency decay: half-life 24h
κ-smoothing for the index
ρ = confidence/volume flag — separates one loud caller from real consensus

PART B — NLP SCORING RULES (from nlp_engine.py)
Sentiment (pure keyword counting, fixed word lists)
Count bullish hits vs bearish hits from locked word lists.
Confidence = majority count / total sentiment words.
Ties (equal) → neutral at fixed 0.5.
Hype score
CODE
hype_score = hype_hits × 0.15 + CTA_phrases × 0.25   (capped at 1.0)
Substance score (starts at base 0.3, cumulative, cap 1.0)
Signal	Add
2+ numbers (price targets/amounts)	+0.2
1 number	+0.1
any TAO/dTAO mention	+0.15
2+ protocol names	+0.15
30+ words	+0.1
15+ words	+0.05
any URL	+0.1
Influence score
CODE
influence = sentiment_confidence×0.3 + substance×0.4 + hype×0.3
PART C — JURY VERDICT RULES (from jury_bridge.py)
Recommended action
Bullish + influence ≥ 0.5 → accumulate
Bearish + influence ≥ 0.5 → reduce
else → hold
Consensus score
CODE
consensus = substance×0.35 + influence×0.25 + (1 − hype×0.3)×0.2 + 0.2   (clamped 0–1)
Predicted direction & magnitude
Sent bullish + influence ≥ 0.4 → up, magnitude influence×0.15
Sent bearish + influence ≥ 0.4 → down, magnitude influence×0.1
else → neutral, magnitude 0.0
Predicted timeframe ladder
Condition	Timeframe
substance > 0.6 AND influence > 0.6	1h–4h
substance > 0.4	4h–24h
else	24h–7d
Verdict + conviction
conviction = base_confidence × 100 (0–100 range)
predicted_confidence = (base_confidence + influence) / 2
PART D — PRICE OUTCOME TRACKING (from price_tracker.py)
What's recorded per message
Snapshot price at message time — TAO/USD and per-subnet alpha token (for messages mentioning a specific subnet/netuid)
Data source: same taomarketcap SQLite cache the dashboard uses; per-subnet price fetched once per run batch
Fields on price_outcomes: pump_pct_max, time_to_pump, pump_duration, resurgence
Outcome classification
A call resolves into one of: pump, mild_pump, dump, mild_dump, stable (exact %-change cutoffs for pump vs mild_pump live in check_outcomes — flagged as the one number to confirm from source; do not guess).

Correct-prediction rule (from self_learning.py _is_correct_prediction)
Verdict / direction	Correct iff
bullish / up	outcome ∈ {pump, mildpump} OR pumppct_max > 2.0
bearish / down	outcome ∈ {dump, mild_dump}
neutral / else	outcome == stable
Accuracy
CODE
accuracy_score = correct / total   (rounded 4dp)
PART E — SELF-LEARNING / REPUTATION RULES (from self_learning.py)
Pattern archetypes tracked
Pattern	Match rule
highsubstancebullish	substance > 0.6 AND bullish
highhypepump	hype > 0.5 (predicts pump)
specificsubnetmention	mentions subnet #
taoamounttarget	has TAO amount target
lowsubstancehigh_hype	substance < 0.3 AND hype > 0.6 (noise)
Pattern confidence
CODE
confidence = (success_rate − 0.5) × min(1, total/10)   (clamped 0–1)
Weight learning (Phase-0 quarantine rules — MUST respect)
Weight adjustments route through nudge_expert in internal.council.weights.
NEVER renormalize council weights to sum → 1.0.
start_background_learning is quarantined off boot — do not call from server.py/background_boot; keep it off the prod hot path.
On resolve: nudge expert ±0.02/−0.03 per pattern; signal weights nudged per-horizon/per-signal.
Judges do not select picks; judges are public quality scorers (Oracle/Echo/Pulse) with no weight feedback — separate from the internal council experts (quant/hype/dark_horse/technical).
