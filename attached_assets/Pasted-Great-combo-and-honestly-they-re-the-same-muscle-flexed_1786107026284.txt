## Roadmap that builds the pitch, in order of closure

**Phase 1 — Surface the receipts (fastest win, ships this week)**
The infrastructure is already there (`author_reliability`, `price_outcomes`, `message_verdicts`). This phase is mostly *exposure*, not new plumbing:
- **Public Caller Leaderboard** — per-author strike rate over 7/30/90d, with their actual calls listed as receipts. Assignment: read `author_reliability.accuracy_score` → new dashboard panel + `/api/caller-leaderboard` endpoint. Small, high-bling.
- **Call Proof cards in the Live Feed** — when a call resolves, show ✓/✗ inline under the original message ("called 4h out — hit ✔"). This is the visible loop that builds trust.

**Phase 2 — One consensus number (the compounding asset)**
- **Live "market conviction" per subnet** — conviction-weighted by each caller's track record, so the site's number gets *smarter* the longer it runs. Feeds from `message_verdicts` + `author_reliability`. This is the thing that has no equivalent in a raw sentiment feed — it's *earned* credibility, and it compounds daily.

**Phase 3 — The "they said it first" proof (differentiation)**
- **Divergence panel** — crowd was early & right, or loud & wrong. Maps to the narrative curve (new → rising → peaking → decaying) so it reads as *stories*, not ranks.

**Phase 4 — Close the price-to-message learning loop**
- Wire `pattern_correlations` (trend → success) back into council weights so the engine literally learns from every resolved call. This is the "it gets smarter" proof — the honest moat.
