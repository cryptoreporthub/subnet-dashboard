## Information architecture (decision order)

1. **Trust** — hit-rate % + n= (proof before pitch)
2. **Census** — how many names in lead / live / exit
3. **Primary lead** — one subnet worth acting on now
4. **Formation meter** — % to trigger (not price chase hero)
5. **Phase rail** — Stir → Build → Pump → Cool
6. **Verdict** — move + thesis + bordered trigger (early vs chase honesty)
7. **Evidence** — Formation / Confirm / Gap with plain captions
8. **Triad** — Inflow / Pressure / Coil with STRONG·RISING·OPEN labels
9. **Size cliff** — liquidity honesty line
10. **CTAs** — dossier + depth
11. **Ladder** — secondary rows with reason + triad + flow/gap
